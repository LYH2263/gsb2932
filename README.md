# ProgLearn - 编程教学互动网站

## 🛠 技术栈

- **Frontend**: Vue 3 + Vite + Element Plus + Pinia + Vue Router
- **Backend**: FastAPI + SQLAlchemy + PostgreSQL
- **Database**: PostgreSQL
- **Deployment**: Docker + Docker Compose

## 🚀 启动指南

确保 Docker Desktop 已启动，然后在根目录执行：

```bash
docker compose up --build
```

等待容器启动完成（首次启动需要下载镜像，可能需要几分钟）。

## 🔗 服务地址

- **Frontend**: http://localhost
- **Backend API**: http://localhost:8000
- **Backend Swagger**: http://localhost:8000/docs

## 📝 开发说明

### 后端开发
后端基于 FastAPI 框架，使用 ORM SQLAlchemy 管理数据库。

**启动后端（开发环境）**:
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### 前端开发
前端基于 Vue 3 + Vite，使用 Element Plus UI 组件库。

**启动前端（开发环境）**:
```bash
cd frontend
npm install
npm run dev
```

## 🔧 环境变量

后端环境变量（通过 docker-compose.yml 配置）:
- `DATABASE_URL`: PostgreSQL 数据库连接字符串
- `SECRET_KEY`: JWT 密钥
- `ACCESS_TOKEN_EXPIRE_MINUTES`: Token 过期时间
